# 💳 Self-service Card Issuing Platform

A lightweight, responsive self-service card issuing platform compatible with both mobile and desktop devices, Support multiple languages. Built with [Nuxt 3](https://nuxt.com/), it's ideal for small businesses or developers to quickly launch a virtual product sales page.

---

## ✨ Features

- ✅ **Restock Email Notifications**  
  Automatically send email notifications when products are restocked

- ✅ **Flexible Admin Configuration**  
  Easily configure product info and delivery methods (auto/manual)

- ✅ **Multiple Payment Methods (Customizable)**  
  Supports mainstream gateways with customizable options

---

## 🛠 Setup & Development

Install dependencies:

```bash
npm install
# or
pnpm install
# or
yarn install
# or
bun install
```

Run the development server (`http://localhost:3000` by default):

```bash
npm run dev
# or
pnpm run dev
# or
yarn dev
# or
bun run dev
```

## 🚀 Build & Deployment
