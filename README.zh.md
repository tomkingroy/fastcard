# 💳 自助发卡平台

一个轻量级、响应式的自助发卡平台，兼容移动端与桌面端，支持多语言，基于 [Nuxt 3](https://nuxt.com/) 构建，适用于小型商家或个人开发者快速上线虚拟商品销售页面。

---

## ✨ 功能特性

- ✅ **补货邮件通知**  
  商品补货时自动发送邮件通知订阅用户

- ✅ **灵活的后台配置**  
  后台可配置商品信息、发货方式（自动或手动）

- ✅ **多种支付方式支持（可定制）**  
  支持主流支付方式，可根据需求扩展定制

## 🛠 安装与启动

确保安装依赖：

```bash
npm install
# 或
pnpm install
# 或
yarn install
# 或
bun install
```

启动开发服务器（默认地址为 `http://localhost:3333`）：

```bash
npm run dev
# 或
pnpm run dev
# 或
yarn dev
# 或
bun run dev
```
